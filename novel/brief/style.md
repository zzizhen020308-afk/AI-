# 风格指令

- **语言**：中文（简体）
- **视角**：第三人称限知，按章切换（哈利视角 / 德拉柯视角），章内不越界。每章视角写在 beat 开头。
- **时态**：过去时
- **句子**：长短交替。情绪高点用短句；场景、回忆可以用长句。避免翻译腔和书面语对白。
- **对话**：占比高（目标 40%），要有交锋、有潜台词。德拉柯的台词必须带刺，哈利的台词要笨拙但真诚。
- **参考**：简·奥斯汀的机锋与"话里有话"；《Normal People》式的克制与身体细节。**不要**参考网文甜宠的节奏。
- **情感表达**：用动作、物件、停顿、视线。不写"心跳加速"，写"他把魔杖换到左手，才发现右手全是汗"。
- **章节结尾**：每章留一个没落地的张力（不一定是悬念，可以是情绪没落地）。

## 禁忌
- 不要露骨性描写（角色 15–18 岁），亲密止于克制的触碰与暗示。
- 不要心理直述："他知道""她明白""他意识到"。
- 不要总结式抒情、不要排比堆砌、不要用天气隐喻心情。
- 不要"邪魅 / 勾唇 / 薄唇 / 眼底闪过一丝 / 语气危险"。
- 不要让角色说现代网络用语（"破防""上头""拿捏"）。
- 不要让德拉柯一开口就是"哼，破特"——她的刺要有具体内容。
